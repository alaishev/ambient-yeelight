# Эмулятор ламп Yeelight

[English](README.md) | **Русский**

Заменяет настоящие лампы при проверке приложения: отвечает на поиск, принимает команды по
локальной сети и показывает цвет каждой лампы в своём окне. Протокол — по
`docs/Yeelight_Inter-Operation_Spec.pdf`.

## Запуск

Нужен Python 3.10 или новее с `tkinter` (в Ubuntu: `sudo apt install python3-tk`).

    python3 lamp_emulator.py lamps.conf

Закрытие любого окна или Ctrl+C в консоли завершает эмулятор.

Компьютер и устройство с приложением (ТВ или телефон) должны быть в одной сети. Если включён
файрвол, откройте UDP-порт поиска и TCP-порты ламп:

    sudo ufw allow 1982/udp
    sudo ufw allow 55443:55444/tcp

Эмулятор Android на том же компьютере не подходит: он за NAT, поиск до него не доходит.

## Настройки

`lamps.conf` — список ламп, в формате JSON:

| Поле | Что |
|---|---|
| `id` | id лампы, по нему приложение её узнаёт |
| `name`, `model` | имя и модель, как в ответе на поиск |
| `port` | TCP-порт управления, у каждой лампы свой |
| `music_mode` | поддерживает ли лампа music mode |
| `power`, `bright`, `color_mode`, `rgb`, `ct`, `hue`, `sat` | начальное состояние; `color_mode`: 1 — rgb, 2 — цветовая температура, 3 — hsv |

Состояние в файл не записывается: после перезапуска лампы снова такие, как в настройках.

## Что эмулируется

- **Поиск**: ответ на `M-SEARCH` по multicast и на запрос прямо на адрес компьютера, за все
  лампы сразу.
- **Команды**: `get_prop`, `set_power`, `set_rgb`, `set_ct_abx`, `set_hsv`, `set_bright`,
  `set_music`. Цвет и яркость принимаются только у включённой лампы. Неизвестное свойство в
  `get_prop` — пустая строка; без music mode пустой и `music_on`.
- **Плавность**: `smooth` с длительностью меняет цвет в окне постепенно.
- **Уведомления**: после изменения лампа шлёт `props` во все соединения, после ответа на команду.
- **Лимиты**: не больше 4 соединений, 60 команд в минуту на соединение, 144 на лампу; сверх
  лимита — ответ с ошибкой.
- **Music mode**: лампа подключается к приложению; команды без ответов, без лимитов и без
  уведомлений.

В консоли — каждая команда и её результат, подключения, отказы по лимитам. Внизу окна: питание,
цвет, яркость, число соединений, команд за минуту и music mode.

Тексты ошибок придуманы: в спецификации их нет. Приложению важен только факт ошибки.
