# План доработки ambient-yeelight

Цель: довести черновой вариант до готового продукта. Основная платформа Android TV, на телефоне
приложение тоже работает.

## Сборка и чистка

- [x] 1. Убрать Compose: тема `ui/theme/*`, плагин и зависимости.
- [x] 2. Сборка: Kotlin DSL, `libs.versions.toml`, AGP 8.10.1, Kotlin 2.1.21, Java 17, minSdk 28,
  viewBinding, явные зависимости.
- [x] 3. Удалить мёртвый код: `LightControl`, `DeviceState`, `CIE94ColorDistanceCalculator`, лишнее
  из `Utils`, `saveToFile`, `calculateHSV`, захардкоженные IP, `TODO()` в `onBind`.
- [x] 4. Логгер в стиле jbagent (`d/i/w/e` с `Throwable`, без `String.format`), чистка
  `AmbientLightApp`.

## Лампы

- [x] 5. Модель `Device` (data class, ключ `id`) и `Settings` вместо `PreferenceManager`, одно
  место хранения ламп и параметров.
- [x] 6. `Discovery`: поиск SSDP с таймаутом, слияние найденных ламп с сохранёнными.
- [x] 7. `Connection`: постоянное TCP-соединение, таймауты, очередь команд, схлопывание цветов,
  лимит частоты.
- [x] 8. Разделить `Connection` на протокол (`Connection`, не больше 60 команд на
  соединение) и политику (`LampController`): лимит 144 команды в минуту, переоткрытие
  соединения, переподключение, схлопывание цветов.
- [x] 9. Music mode (`set_music`) с откатом на обычное соединение.
- [x] 10. Состояние ламп: сохранить при старте, включить, восстановить после остановки.

## Захват и цвет

- [ ] 11. `ScreenCapture`: уменьшенный VirtualDisplay, `MediaProjection.Callback`, освобождение

- [ ] 12. `ColorExtractor`: доминирующий цвет, яркость по картинке, приглушение в тёмных сценах.
- [ ] 13. Сервис: корректные старт и стоп, без перезапуска без разрешения, `StateFlow` со статусом,
